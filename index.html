Attempts a complete in-browser IPSW rebuild: SilverDB → FAT16 → IMG1 → MSE → IPSW. The IMG1 signature will be zeroed and invalid. The resulting IPSW cannot be flashed on stock hardware. Use with ipod_sun or ipod_theme exploit tooling.

About NanoForge

What is NanoForge?

NanoForge is a browser-based research and development toolkit for creating custom firmware for the Apple iPod nano 6th and 7th generations. It runs entirely client-side — no server, no installation required.

IPSW Parsing Pipeline

NanoForge parses firmware using this chain:

  • IPSW (ZIP) → Firmware.MSE (partition container)
  • MSE → rsrc.img1 (Apple IMG1 format, v2.0)
  • IMG1 body → FAT16 filesystem
  • FAT16 → SilverImagesDB.LE.bin (asset database)
  • SilverDB → Individual images (BGRA, RGB565, greyscale, paletted)
